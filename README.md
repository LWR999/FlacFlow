# FlacFlow

Automated FLAC Music Library Metadata Processing System for Roon Server

## Features

- Web-based interface for batch processing FLAC albums
- Automatic metadata extraction from folder names
- Multi-disc album support (preserves Disc 1/Disc 2 structure for Roon)
- Artwork resizing and embedding
- Quality-based organization (CD vs Hi-Res)
- Delete and publish functionality
- Progress tracking for long operations
- Runs as a system service
